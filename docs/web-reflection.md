# Web UI Reflection

The CLI calculator takes input through the terminal using Scanner, where the user enters numbers and operators as text. The web calculator collects input through buttons, which gives the user a more visual and interactive interface. 
In the CLI version, the program directly processes the input from the terminal, while the web version currently only provides the visual layout. The web UI is easier to use visually, but it needs additional logic to actually perform calculations.

JavaScript would be needed to handle button clicks, update the display, and perform the calculations.
